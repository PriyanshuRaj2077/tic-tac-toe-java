# Tic Tac Toe Game in Java

A simple console-based Tic Tac Toe game built using Java.

## Features

* Two-player gameplay
* 3x3 board
* Win detection
* Draw detection
* Input validation for occupied cells

## Technologies Used

* Java
* 2D Arrays
* Loops
* Conditional Statements

## How to Run

1. Compile the code:
   javac TicTacToe.java

2. Run the program:
   java TicTacToe
